# 趋势弹窗：工作区间与用户设备（1.3.8）

依据用户截图标注：ChartModal 标题改为可配置「工作区间」，设备下拉改为用户自管。

## 新交互

1. 在「环境与设备」点击任意传感器卡片，打开趋势弹窗。
2. **工作区间**（左上输入框）
   - 默认名：温度/湿度/空气质量工作区间
   - 可改成任意名称（如「菌房 A 区」「冷库门帘」），**不必是温度或湿度**
   - **单位**可在右上「单位」框修改（℃、%、ppm…）
   - 下限 / 上限（或 AQI 仅上限）照旧可改
3. **设备**（右上）
   - 下拉为你自己的设备列表（首次有一台「默认设备」）
   - **＋** 添加并自动选中
   - **✎** 重命名当前选中设备
   - **－** 删除当前设备（至少保留一台；删后其它区间若绑了它会改绑到剩余第一台）

## 持久化

| Key | 内容 |
|-----|------|
| `localStorage.naijiaren.devices` | `[{ id, name }]` |
| `localStorage.naijiaren.workZones` | 每通道 `{ name, unit, color, rangeMode, step, deviceId, channel }` |
| `localStorage.naijiaren.thresholds` | 上下限 + `deviceId`（替代旧 `target: buzzer\|relay\|both`） |

## 与硬件的关系

- 实时值与历史曲线仍按通道 `temp` / `humidity` / `aqi` 取 MQTT 上行（`channel` 字段预留扩展）。
- 阈值越界仍下发白名单指令 `buzzer:on` / `buzzer:off`；**设备名只出现在 UI 与日志**，固件侧暂未按设备分拆。

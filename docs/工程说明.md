# 工程说明：基于 STM32 的环境监测 Electron 上位机

> 课题 / 仓库名：**基于 STM32 的环境监测 Electron 上位机**  
> 桌面产品名：奶家人（Naijiaren） · 当前版本 **v1.3.10**  
> 本仓库是面向 STM32 环境监测节点的 Windows 桌面上位机，技术栈为 Electron + Vue 3 + Three.js + MQTT。  
> 协议与 STM32（dht11）固件冻结，主题和字段请勿随意改动。  
> 配套文档：根目录 `README.md`、`CHANGELOG-奶家人.md`。

---

## 一、项目定位

本工程解决的是「现场传感器节点如何在电脑上被监视和控制」：

1. STM32 采集温度、湿度、AQI 等环境量，并可上报按键旋向等状态。
2. 数据经 ESP8266 发布到 MQTT Broker。
3. 本上位机在 Windows 上订阅同一 Broker，做实时展示、阈值报警、历史曲线、数字孪生屏显，并在白名单内下发蜂鸣器、风扇、呼吸灯、皮肤等指令。

桌面端内部曾用名 wenwen / qiuqiu，产品打包名为「奶家人」；对外课题名称统一为上面的标题。

## 二、系统架构

```
┌────────────┐    UART/Wi-Fi     ┌──────────┐     MQTT      ┌─────────────────────┐
│ STM32 节点 │ ───────────────► │ ESP8266  │ ───────────► │ MQTT Broker         │
│ 传感 / 执行 │ ◄─────────────── │ 透传上报  │ ◄─────────── │ 主题见第四节        │
└────────────┘                   └──────────┘              └──────────┬──────────┘
                                                                     │
                                                           主进程订阅 / 发布
                                                                     ▼
                                                      ┌──────────────────────────┐
                                                      │ Electron 桌面上位机      │
                                                      │  window / IPC / 白名单    │
                                                      │  Vue 界面 + Three.js 孪生 │
                                                      └──────────────────────────┘
```

- **硬件层**：STM32 负责采集与执行；屏显参考 LVGL MyUI（见 `docs/myui-reference/`、`docs/firmware-skins/`）。
- **传输层**：默认主题为 `device/stm32/sensor_data`（上行）与 `device/stm32/commands`（下行）。
- **上位机主进程**：`electron/` 管理窗口、MQTT 连接和指令白名单，不把任意字符串直接发给设备。
- **渲染进程**：`src/` 用 Vue 3 做监视与控制界面，用 Three.js 加载 `public/model.glb`，并把环境数据画到模型屏显纹理上。

配置只有一个真源：`shared/defaults.json`。前端 `src/config.js` 与主进程 `electron/config.cjs` 都读它，避免两处各写一套 Broker / 主题 / 阈值。

## 四、通信协议

与固件约定如下，属于冻结接口。

| 方向 | 主题 | 载荷 |
|------|------|------|
| 上行 | `device/stm32/sensor_data` | JSON：`temp` / `humidity` / `aqi` / `btn`（仅 `CW` / `CCW`）；可选 `breath` / `fan` / `buzzer` / `battery` / `wifi` |
| 下行 | `device/stm32/commands` | `buzzer:on\|off`、`breath:on\|off`、`fan:on\|off`、`skin:*`，末尾带换行 `\n` |

说明：

- `breath` / `fan` 若固件未接，下行指令不会生效。
- 主进程只允许 `shared/defaults.json` 里的 `allowedCommands`，并校验 Broker 主机与协议白名单。
- 生产模式（`NAIJIAREN_MODE=production`）强制使用 `mqtts` 或 `wss`。

**上行数据流：**

```
STM32 → ESP8266 → MQTT device/stm32/sensor_data
  → electron/mqtt-manager → IPC → App.vue → useSensorData
  → useAlarm / 监测卡片 / 3D 屏显 / 历史曲线
```

**下行控制流：**

```
报警 / 屏点击 / 中控（手动、场景、自动风扇）
  → sendCommand（白名单）→ device/stm32/commands → 硬件
```

## 五、功能说明

| 模块 | 说明 |
|------|------|
| 环境监视 | 温度、湿度、AQI 实时刷新；超过 `dataTimeoutMs`（默认 8 秒）无数据视为离线 |
| 报警 | 阈值来自 `shared/defaults.json` 的 `thresholds`（默认温度 18–28℃、湿度 40–70%、AQI 100） |
| 历史与导出 | 本地记录趋势，弹窗查看，可导出 Excel |
| 数字孪生 | 3D 模型 + 与硬件 LVGL MyUI 对齐的屏显纹理和皮肤 |
| 设备控制 | 蜂鸣器、呼吸灯、风扇、皮肤切换；受指令白名单约束 |
| 设备与区间 | 设备管理、工作区间、自动控制逻辑 |
| 安全与登录 | operator / admin 两档演示登录；Broker 与指令白名单 |
| 安装 | NSIS 可选路径 + 许可协议；安装向导原型见 `docs/installer-prototype.html` |

界面皮肤（下发 `skin:*`，与固件侧风格对应）：工业深色、雾蓝静谧、柔和家居、运维青金。

## 七、开发与运行

```bash
npm install
npm run dev            # Vite + Electron 开发
npm run build          # 仅前端打包
npm run dist           # Windows NSIS 安装包输出到 release/
npm run mock:broker    # 本地 MQTT Broker
npm run mock:stm32     # 模拟 STM32 上报
npm run mock:roundtrip # 上下行联调
```

环境变量：`NAIJIAREN_MODE=demo|production`。

演示账号（仅开发 / 演示，部署请替换）：

- `operator` / `naijia2026`
- `admin` / `admin2026`

## 八、想改某项时改哪个文件

| 需求 | 文件 |
|---|---|
| 默认 Broker / 主题 / 阈值 / 皮肤列表 | `shared/defaults.json`（以及读取它的 `src/config.js`、`electron/config.cjs`） |
| 识别哪些传感器字段 | `src/composables/useSensorData.js` |
| 报警阈值与逻辑 | `src/composables/useAlarm.js` + 配置 |
| 历史曲线 | `useHistory.js` + `useChart.js` + `ChartModal.vue` |
| 面板 UI | `src/components/*` + `styles.css` |
| 中控 / 自动风扇 / 场景 | `DeviceControlPanel.vue` 或环境监视相关面板 + `useAutoControl.js` |
| 本地无硬件联调 | `scripts/mock-broker.mjs` / `mock-stm32.mjs` / `mqtt-roundtrip.mjs` |
| 3D / 屏显 / 交互 | `src/three/ThreeEngine.js` + `screenTheme.js` |
| IPC 通道 | `preload.cjs` + `electron/ipc.cjs` |
| 安装包文案与钩子 | `installer/` + `package.json` 的 `build` 字段 |

## 九、已知限制

- 代码签名与自动更新尚未接入

## 维护注释

本轮（1.3.7，未升版）为源码补了**详细中文维护注释**，约定如下。

### 注释写什么

每处维护注释尽量说明：

1. **做什么** — 模块/函数职责  
2. **为何这样写** — 设计取舍（如双击延迟、白名单、capture 锁轨道）  
3. **改时注意** — 易踩坑、禁止事项、须同步的文件  
4. **依赖关系** — 上下游模块 / 协议字段 / localStorage 键  

### 注释不写什么

- 不写「定义变量」「返回结果」这类复述代码的废话  
- 不改运行逻辑、不升版本号  
- `shared/defaults.json` 不能写 JSON 注释 → 旁注见 `docs/defaults字段说明.md`

### 复杂逻辑必读位置

| 主题 | 位置 |
|------|------|
| OrbitControls 亮度拖动锁定 | `ThreeEngine.js` → `setOrbitDuringBrightnessDrag` + `pointerdown` capture |
| 灯单击/双击菜单 | `ThreeEngine.js` → `handleScreenUvHit`（`BREATH_DBL_MS`） |

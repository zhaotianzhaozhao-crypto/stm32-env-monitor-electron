# 1.3.9 · 趋势二级菜单 + 设置设备配置

## 趋势弹窗怎么进二级菜单

1. 打开任意传感器卡片趋势弹窗
2. 顶栏右侧点「设置」（齿轮）
3. 右侧滑出「区间设置」：绑定设备（＋✎－）、下限/上限/单位
4. 再点「设置」或侧栏「›」收起

顶栏保留：工作区间名称、用途备注（如「数据采集」）、设置入口、关闭。

## 设备–指令数据结构

`localStorage` 键：`naijiaren.devices`

```json
[
  {
    "id": "dev_…",
    "name": "默认设备",
    "commands": ["buzzer:on", "buzzer:off"]
  }
]
```

- 与趋势弹窗设备下拉同一 `useDevices` 源
- 「发」→ `electronAPI.sendCommand(cmd)` → 主进程 `isAllowedCommand`；未进白名单会被拒
- 工作区间 `note` 字段存在 `naijiaren.workZones[channel].note`

## 设置页入口

侧栏 Tab「设置」→ 连接设置下方「设备配置」左右分栏。
